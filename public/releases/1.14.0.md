# 知行 1.14.0：代码实操「人话任务书」全面改版

本轮面向全部 85 节课程的第 5 关「代码实操」，把原本高度压缩的单段技术规格改写并重构为直观易懂的「人话任务书」，降低读题门槛，让注意力回到理解概念与动手写代码本身。

## 代码实操任务书升级

- **运行模式一目了然**：题头新增模式徽章与简短提示，明确标出当前题目属于「可直接运行 JS」「HTML + CSS + JS 联动预览」还是「代码方案题 · 提交 AI 评阅」。
- **一句话目标 + 真实业务场景**：全站 85 道题均补写大白话目标与实际开发场景（独立存于 `public/challenge-guides.json`），不再上来就被一长串密集需求劝退。
- **输入 → 期望输出对照表**：在编辑器上方直接呈现 2–3 组具体输入/操作、期望结果和背后原因（平板和手机端支持横向滚动查看，不撑破页面）。
- **本关验收清单前置**：将原本折叠在第 6 关「代码评阅」里的评分要点（`rubric`）直接展示在写代码之前，写完即可逐条自检。
- **按需展开辅助工具**：
  - 「没思路？展开分步拆解」：给出 3–4 步非剧透思考拆解；
  - 「还需要一点提示？」：合并原有提示与本题术语白话词典；
  - 「查看原始精简题意」：随时对照原始紧凑规格；
  - 「✧ 让助教用大白话再讲一遍题意 →」：一键定位当前实操题，把需求交给右侧 AI 助教用生活化例子再讲一遍。

## 兼容性与记录保护

- 严格保持 `public/data/frameworks.json` 与 `public/data/platform.json` 的原有实操契约与哈希不变，既有代码草稿、历史评阅、还原点与模型配置全部无缝沿用。
