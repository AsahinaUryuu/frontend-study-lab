返回学习软件助教与输入放大阅读学习与练习

启动与恢复

  1. 再次双击启动文件，会识别并关闭同目录的旧服务，再启动新版本。
  2. 能够清理本软件遗留的独立 BAT 启动窗口，包括之前启动失败后停留的窗口。
  3. 连续双击时串行处理启动请求，避免同时争抢端口。
  4. 服务通过健康检查后再打开浏览器，减少启动时空白页和连接失败。
  5. 端口被其他软件占用时给出明确提示；启动错误写入本机日志，便于排查。

助教与输入

  1. Ctrl 在更早的按键处理阶段接管，阻止后续输入框监听器和原生换行动作覆盖发送操作。
  2. 新增“检测按键”：显示实际收到的键、修饰键和将执行的操作；检测期间不发送问题，草稿只读。
  3. 新增“重新录制发送键”：按实际收到的 Ctrl 或 Enter 保存发送方式，适配按键映射。
  4. 发送方式可在单按 Ctrl、Ctrl+Enter、Enter 三种模式间选择，并在刷新后保留。
  5. 输入框随内容自动增高，到达上限后内部滚动，避免长问题难以编辑。
  6. 显示问题字数、保存结果和接近长度上限的提示；空问题不能点击发送。
  7. 清空草稿后可撤销；把历史问题放回输入框时也能恢复此前草稿。
  8. 历史问题可“编辑后重发”，先修改草稿，再由自己决定发送。
  9. 侧栏中的整条问题和回答均可复制；回答保留原始 Markdown。
  10. 请求失败后保留问题并提供重试入口，不会重复写入失败消息。
  11. 等待回复时显示已等待秒数，并继续提供停止操作。
  12. 阅读旧消息时，新回复不强制抢走滚动位置；可点击“最新”跳转。

默认仍为单按并松开 Ctrl 发送、Ctrl+Shift 换行。若你的系统把实体 Ctrl 映射成其他按键，可打开输入框下方“输入设置 · 快捷键检测”，先查看实际事件，再重新录制。这里不会记录问题正文或把按键数据发给模型。

放大弹窗阅读

  1. 正文字号可在 12–26px 调整，支持 A− / A+、滑块和恢复默认；刷新后记忆。
  2. 行距可选紧凑、标准、宽松，并保存偏好。
  3. 明亮、纸张、深色三种正文配色，可保存。
  4. 舒适行宽与铺满窗口可切换，适应长文和宽代码。
  5. 长代码可自动折行，复制时仍是完整原代码。
  6. 可查找当前对话，高亮关键词，显示数量并跳转上一个、下一个匹配。
  7. 按会话记住阅读位置，关闭重开或当前标签刷新后恢复。
  8. 常驻“开头”和“最新”按钮，并显示阅读旧回答时收到的新消息数量。
  9. 弹窗可复制整条回答为 Markdown。
  10. 当前对话可导出为 Markdown 文件，只包含当前会话已提交消息。

所有阅读设置集中在折叠工具栏内。输入区继续与侧栏共享，草稿、发送、停止和错误状态同步。

学习与练习

  1. 返回或刷新课程时继续上次关卡，首页“继续学习”也显示对应环节。
  2. 课程可以收藏，并通过“我的收藏”筛选集中复习。
  3. 增加“最近学习”，按最近访问顺序找回课程。
  4. 课程可按学习路径、最近访问或标题排序，筛选与排序偏好会记忆。
  5. 搜索结果显示匹配数量，并可一键清除搜索和筛选。
  6. 每课增加自动保存的个人笔记，随学习记录一起导入、导出。
  7. 教材正文字号可调整并记忆。
  8. 教材行距可调整并记忆，阅读设置可恢复默认。
  9. 增加上一关、下一关按钮，显示当前关卡位置。
  10. 增加上一课、下一课入口，减少回目录寻找的次数。
  11. 练习显示已答题数和剩余题数，并提供带作答状态的题号导航。
  12. 可直接跳到第一道未答题，全部完成后按钮自动禁用。
  13. 有未答题时先在练习内提醒，由你选择继续完成或明确提交当前答案。
  14. 反馈同时展示当次提交答案、参考答案和解析，修改草稿不会改写提交记录。
  15. 反馈可只看错题与未答题，全部答对时显示对应提示。
  16. 仅重做错题时保留正确答案和原评测记录。
  17. 每题反馈提供返回修改入口，直接定位到对应答案框。
  18. 原书逐题讲解支持全部展开 / 收起，并增加返回本课顶部入口。

数据与验证说明

升级不重置学习记录，不改写你的 API Key。新增笔记与收藏包含在学习记录导出中；阅读和按键偏好保存在当前浏览器。

本次验证使用本机模拟回复与自动化测试，没有使用真实模型额度。按键检测支持进一步区分“网页处理错误”和“系统实际发来其他按键”这两种情况；本次未能完成你所用 Chrome 的实体键盘复测。
